# VPN・リモート接続マニュアル

株式会社サンプル 情報システム部（ダミー資料。実在の製品とは関係ありません）
2026年8月1日版

## 1. VPN とは
VPN は、社外から社内のネットワークに安全に接続するための仕組みです。会社の PC には、VPN のソフトウェア「サンプル VPN クライアント」が最初から入っています。

## 2. VPN が必要なとき
次のシステムは、社外からは VPN に接続しないと使えません。
- 社内ファイルサーバー
- 基幹システム（販売管理・在庫管理）
- 開発用サーバー（開発部のみ）

メール、チャット、社内ポータル、人事システム、経費システムは、VPN に接続しなくても使えます（多要素認証は必要です）。

## 3. 接続のしかた

### 3.1 接続の手順
1. タスクバーの「サンプル VPN クライアント」のアイコンをクリックする
2. 接続先で「本社」を選ぶ
3. 会社のアカウントでサインインし、認証アプリで承認する
4. アイコンが緑色になったら接続完了

### 3.2 接続を切る
業務が終わったら、アイコンをクリックして「切断」を選んでください。8時間たつと自動で切断されます。

## 4. つながらないとき

### 4.1 よくある原因
| 症状 | 原因と対処 |
| --- | --- |
| 「認証に失敗しました」と表示される | パスワードが間違っているか、アカウントがロックされています。「PC・アカウント利用ガイド」2.3・2.4を参照 |
| 接続中のまま進まない | インターネットにつながっているか確認してください。ホテルなどの Wi-Fi では、ブラウザで利用規約に同意してから接続します |
| 接続してもファイルサーバーが開かない | 一度切断して、もう一度接続してください |
| 「証明書の有効期限が切れています」と表示される | 社内のネットワークに一度接続すると更新されます。出社できない場合はヘルプデスクに連絡してください |

### 4.2 それでもつながらないとき
ヘルプデスク（内線1234、it-help@example.co.jp）に、表示されたエラーメッセージの画面写真を添えて連絡してください。

## 5. 海外から接続するとき
海外から VPN に接続する場合は、出発の5営業日前までに、社内ポータルの「海外利用申請」を提出してください。申請がない場合、海外からの接続は自動で遮断されます。

## 6. 注意事項
- 公衆 Wi-Fi を使うときは、必ず VPN に接続してください（情報セキュリティポリシー第20条）
- VPN に接続したまま、私的な Web サイトを見ないでください
- 家族と共用のネットワークでも使えますが、画面をのぞき見されないよう注意してください
