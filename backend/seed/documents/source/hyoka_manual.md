# 人事評価運用マニュアル（評価者向け）

株式会社サンプル 人事部（ダミー資料。人事部内のみ公開）
2026年4月1日版

## 1. 評価制度の概要

### 1.1 評価の目的
人事評価は、従業員の成果と行動を公正に評価し、処遇（昇給・賞与・昇格）と育成に反映することを目的とする。

### 1.2 評価の構成
評価は「成果評価」と「行動評価」の2つで構成する。一般職は成果評価50%・行動評価50%、管理職は成果評価70%・行動評価30%の比率で総合評価を算出する。

### 1.3 評価期間
評価期間は上期（4月〜9月）と下期（10月〜3月）の年2回とする。

## 2. 評価のスケジュール

### 2.1 年間スケジュール
| 時期 | 内容 | 担当 |
| --- | --- | --- |
| 4月上旬 / 10月上旬 | 目標設定面談 | 一次評価者 |
| 7月 / 1月 | 中間面談 | 一次評価者 |
| 9月下旬 / 3月下旬 | 本人の自己評価 | 本人 |
| 10月上旬 / 4月上旬 | 一次評価・二次評価 | 評価者 |
| 10月中旬 / 4月中旬 | 評価調整会議 | 人事部・部長 |
| 10月下旬 / 4月下旬 | フィードバック面談 | 一次評価者 |

## 3. 評価の段階

### 3.1 評価記号
評価は S・A・B・C・D の5段階とする。
| 記号 | 基準 |
| --- | --- |
| S | 期待を大きく上回った |
| A | 期待を上回った |
| B | 期待どおりだった |
| C | 期待をやや下回った |
| D | 期待を大きく下回った |

### 3.2 分布の目安
部署ごとの総合評価の分布は、S 5%、A 20%、B 50%、C 20%、D 5% を目安とする。目安と大きく異なる場合は、評価調整会議で理由を説明する。

## 4. 評価者の留意事項

### 4.1 評価エラー
評価者は、次の評価エラーに注意すること。
- ハロー効果：一部の印象で全体を評価してしまう
- 中心化傾向：B に評価が集中してしまう
- 寛大化傾向：全体的に甘く評価してしまう
- 期末効果：評価期間の終わりの出来事だけで評価してしまう

### 4.2 評価の記録
評価の根拠となる事実は、評価期間中に人事システムの「評価メモ」に記録すること。評価メモは本人には公開されない。

### 4.3 フィードバック面談
フィードバック面談では、評価の結果と理由を具体的な事実に基づいて伝え、次期の目標と育成の方針を話し合う。面談は30分以上行い、面談記録を人事システムに登録する。

## 5. 処遇への反映

### 5.1 昇給
昇給は年1回（4月）とし、前年度の上期・下期の総合評価に基づいて決定する。昇給額の表は人事部が別途管理する。

### 5.2 賞与
賞与は年2回（6月・12月）支給し、直前の評価期間の総合評価を反映する。

### 5.3 昇格
昇格の候補者は、直近2年間の総合評価がA以上を2回以上含む者から、部長が推薦する。

## 6. 異議申立て

### 6.1 申立ての手続き
評価結果に異議がある従業員は、フィードバック面談から2週間以内に、人事部に異議申立書を提出できる。人事部は申立てを受けてから1か月以内に再確認の結果を回答する。
