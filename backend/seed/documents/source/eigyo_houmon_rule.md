# 営業部 顧客訪問・接待ルール

株式会社サンプル 営業部（ダミー資料。営業部内のみ公開。実在の会社とは関係ありません）
2026年4月1日版

## 1. 顧客訪問

### 1.1 訪問の予定登録
顧客を訪問するときは、前日までに営業支援システム（SFA）に訪問予定を登録してください。登録すると、チームのカレンダーにも表示されます。

### 1.2 直行・直帰
朝に会社に寄らずに顧客を訪問する（直行）、又は訪問後に会社に戻らずに帰宅する（直帰）場合は、前日までに所属課長に連絡し、勤怠システムで「直行・直帰」を選択してください。

### 1.3 訪問の記録
訪問後は、当日中に SFA に訪問記録（面談者、内容、次の対応）を入力してください。

### 1.4 移動手段
顧客訪問の移動は、原則として公共交通機関を使います。タクシーは、次の場合に限り利用できます。
- 重い荷物（展示品など）を運ぶとき
- 22:00以降に移動するとき
- 公共交通機関では約束の時刻に間に合わないとき（事前に課長の承認が必要）

## 2. 接待・会食

### 2.1 事前の承認
取引先との会食は、事前に SFA の「接待申請」で課長の承認を得てください。1人あたり10,000円を超える会食は、部長の承認も必要です（経費精算マニュアル 5.2 の上限の例外として、部長が認めた場合に限る）。

### 2.2 公務員の接待の禁止
国や地方自治体の職員など、公務員への接待・贈答は禁止します。

### 2.3 二次会
二次会の費用は、原則として会社の経費にできません。

### 2.4 支払い
会食の支払いは、法人カードを持っている人は法人カードで支払ってください（「法人カード利用ガイド」）。持っていない人は立て替えて、経費システムで精算してください。

## 3. 手土産・贈答

### 3.1 手土産
顧客訪問の手土産は、1回5,000円までとします。経費システムでは「交際費」として精算してください。

### 3.2 お中元・お歳暮
お中元・お歳暮は、営業部で取りまとめて送ります。送り先の追加・削除は、6月10日（お中元）・11月10日（お歳暮）までに営業企画課に連絡してください。

### 3.3 贈答品を受け取ったとき
取引先から贈答品を受け取った場合は、所属課長に報告してください。1件10,000円を超えるものは、お礼の連絡をしたうえで、原則としてお断りします。

## 4. 見積もり・契約

### 4.1 値引きの権限
見積もりの値引きは、次の範囲で承認を得てください。
| 値引き率 | 承認者 |
| --- | --- |
| 10%まで | 担当者の判断 |
| 10%を超え20%まで | 課長 |
| 20%を超えるもの | 部長 |

### 4.2 契約書
契約書のひな形は、社内ポータルの「法務」ページにあります。ひな形を変更する場合は、法務担当の確認を受けてください。

## 5. 営業目標
四半期ごとの営業目標は、期初の営業会議で発表します。目標の達成状況は SFA のダッシュボードで確認できます。
