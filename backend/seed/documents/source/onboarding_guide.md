# 新入社員オンボーディングガイド

株式会社サンプル 人事部（ダミー資料。実在の会社とは関係ありません）
2026年4月版

## 1. 入社初日にすること

### 1.1 初日のスケジュール
| 時間 | 内容 | 場所 |
| --- | --- | --- |
| 9:00 | 受付（社員証の受け取り） | 1F 受付 |
| 9:30 | 入社オリエンテーション | 5F 大会議室 |
| 12:00 | 昼食（配属部署のメンバーと） | 各部署 |
| 13:30 | PC の受け取りと初期設定 | 3F 情報システム部 |
| 15:00 | 配属部署での説明 | 各部署 |

### 1.2 持ち物
- 入社書類（就業規則第5条に定める書類のうち、未提出のもの）
- 印鑑（シャチハタ以外）
- 給与振込口座の通帳又はキャッシュカードの写し

## 2. 最初の1週間

### 2.1 アカウントの準備
初日に受け取った PC で、次の設定を行います。詳しくは「PC・アカウント利用ガイド」を参照してください。
- 初期パスワードの変更（12文字以上）
- 多要素認証（認証アプリ）の設定
- 社内ポータルへのログイン確認

### 2.2 必須の e ラーニング
入社後1週間以内に、社内ポータルの「学習」から次の e ラーニングを受講してください。
- 情報セキュリティ基礎（約60分）
- ハラスメント防止（約30分）
- コンプライアンス基礎（約45分）
- 個人情報の取扱い（約30分）

### 2.3 人事システムの登録
人事システムに、緊急連絡先、通勤経路、扶養家族を登録してください。通勤手当は、通勤経路の登録後に経理部が審査します（「通勤手当規程」）。

## 3. 最初の3か月

### 3.1 メンター制度
新入社員1人に、配属部署の先輩社員1人がメンターとしてつきます。メンターとは週1回、30分程度の面談を行います。仕事の進め方だけでなく、困ったことは何でも相談してください。

### 3.2 試用期間
入社から3か月は試用期間です（就業規則第6条）。試用期間中も、給与・社会保険・年次有給休暇の勤続期間の扱いは本採用後と同じです。

### 3.3 新入社員研修
新卒入社者は、4月の1か月間、全体研修を受講します。中途入社者は、入社月の翌月に1日の中途入社者研修を受講します。

## 4. よくある質問

### 4.1 有給休暇はいつから使えますか
年次有給休暇は、入社から6か月後に10日付与されます（就業規則第30条）。それまでの期間に休む必要がある場合は、所属長に相談してください。

### 4.2 社員食堂はありますか
本社5Fにカフェテリアがあります。営業時間は11:30〜14:00です。社員証で支払いができ、代金は翌月の給与から控除されます。

### 4.3 困ったときはどこに聞けばいいですか
まずは社内ナビAI（チャット）で質問してください。解決しない場合は、担当部署に問い合わせることができます。
