# SNS 利用ガイドライン

株式会社サンプル マーケティング部（ダミー資料。実在の会社とは関係ありません）
2026年2月1日版

## 1. 目的
このガイドラインは、従業員が SNS（X、Instagram、Facebook、LinkedIn、ブログなど）を利用するときに守ってほしいことをまとめたものです。会社の公式アカウントの運用と、従業員の個人アカウントの利用の両方を対象にします。

## 2. 会社の公式アカウント

### 2.1 運用の担当
会社の公式アカウントは、マーケティング部 広報課が運用します。他の部署が公式アカウントで発信したい場合は、投稿の5営業日前までに広報課に依頼してください。

### 2.2 新しいアカウントの開設
部署やサービスごとに新しい公式アカウントを開設する場合は、マーケティング部長の承認が必要です。無断で会社名を使ったアカウントを作ってはいけません。

### 2.3 炎上したとき
公式アカウントの投稿に批判が集まった場合は、担当者だけで返信せず、すぐに広報課長に報告してください。広報課が対応方針を決めます。

## 3. 個人アカウントの利用

### 3.1 基本的な考え方
個人アカウントで何を発信するかは自由ですが、発信した内容によって会社の信用が損なわれることがあります。次のことを守ってください。

### 3.2 してはいけないこと
- 会社の秘密情報（未発表の製品、業績、取引先の情報など）を投稿する
- 社内の写真を投稿する（ホワイトボード、PC の画面、名札などが写り込むおそれがあるため）
- 取引先や顧客の悪口を書く
- 会社を代表しているように見える発信をする

### 3.3 会社名を出すとき
プロフィールに勤務先として会社名を書く場合は、「投稿は個人の意見であり、所属組織を代表するものではありません」と書いてください。

### 3.4 会社の発表を共有するとき
会社が公式に発表した情報（プレスリリース、公式アカウントの投稿）を共有するのは問題ありません。発表前の情報は共有しないでください。

## 4. 取材・登壇の依頼
メディアから取材の依頼を受けた場合、又はイベントでの登壇を頼まれた場合は、引き受ける前に広報課に相談してください。

## 5. 問題のある投稿を見つけたとき
会社や従業員について、事実と違う投稿や、問題のある投稿を見つけた場合は、自分で反論せず、広報課（内線6100）に連絡してください。

## 6. 違反したとき
このガイドラインに違反し、会社の信用を損なった場合は、就業規則に基づき懲戒処分を行うことがあります。
