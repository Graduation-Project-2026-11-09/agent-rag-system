# オフィス利用・来客対応ガイド

株式会社サンプル 総務部（ダミー資料。実在の会社とは関係ありません）
2025年7月1日版

## 1章 総則

### 1.1 本社の概要
本社ビルは地上6階建てで、各フロアの主な用途は次のとおりです。
| フロア | 主な用途 |
| --- | --- |
| 1F | 受付、来客用会議室（応接室A・B） |
| 2F | 営業部、マーケティング部 |
| 3F | 情報システム部、開発部 |
| 4F | 人事部、総務部、経理部 |
| 5F | 大会議室、カフェテリア |
| 6F | 役員室、役員会議室 |

### 1.2 入館
入館には社員証が必要です。社員証を忘れた場合は、1F 受付で仮入館証を受け取ってください。仮入館証は当日中に返却してください。

### 1.3 利用時間
オフィスの利用時間は、平日の7:00〜22:00です。22:00以降に残る場合は、所属長の承認を得たうえで、総務部に「時間外在館届」を提出してください。

## 2章 会議室

### 2.1 会議室の種類
| 会議室 | 定員 | 設備 |
| --- | --- | --- |
| 応接室A・B（1F） | 6名 | モニター |
| 小会議室1〜6（各フロア） | 4〜8名 | モニター、Web会議用カメラ |
| 大会議室（5F） | 80名 | プロジェクター、マイク、配信設備 |
| 役員会議室（6F） | 16名 | 役員の予約が優先 |

### 2.2 予約の方法
会議室は、社内ポータルの「施設予約」から予約します。予約は2か月先まで可能です。1回の予約は最長4時間までとし、定例会議で毎週予約する場合は3か月分まで予約できます。

### 2.3 大会議室の予約
大会議室は、平日の9:00〜20:00に利用できます。30名以上のイベントで利用する場合は、2週間前までに総務部に「大会議室利用申請」を提出し、机・椅子のレイアウトを指定してください。

### 2.4 キャンセル
予約した会議室を使わなくなった場合は、速やかに予約を取り消してください。予約時刻から15分たっても使われていない会議室は、自動で予約が取り消されます。

### 2.5 利用後のルール
- ホワイトボードを消し、机と椅子を元の位置に戻す
- モニターと照明の電源を切る
- 飲み物以外の飲食は、大会議室とカフェテリアに限る

## 3章 来客対応

### 3.1 来客の事前登録
来客がある場合は、前日までに社内ポータルの「来客登録」で、来訪者の会社名・氏名・人数・時刻を登録してください。登録された来訪者は、受付で名前を伝えるとゲスト入館証を受け取れます。

### 3.2 当日の対応
来訪者が受付に到着すると、登録した担当者に通知が届きます。担当者は1F 受付まで迎えに行ってください。来訪者だけで執務フロアに入ることはできません。

### 3.3 お茶出し
応接室A・Bでの来客には、総務部が飲み物を用意します。来客登録の際に「飲み物の用意」を選択してください。それ以外の会議室では、各自で用意してください。

### 3.4 駐車場
来客用の駐車場は2台分あります。来客登録の際に「駐車場の利用」を選択してください。先着順のため、利用できない場合があります。

## 4章 郵便・宅配

### 4.1 郵便物の受け取り
社宛ての郵便物・宅配便は、総務部が受け取り、各部署の郵便ボックスに配ります。配布は1日2回（10:00、15:00）です。

### 4.2 郵便物の発送
業務の郵便物は、総務部の発送ボックスに入れてください。16:00までに入れたものは当日に発送します。速達・書留は「発送依頼票」を添えてください。私用の郵便物は発送できません。

## 5章 その他

### 5.1 忘れ物・落とし物
忘れ物・落とし物は総務部で保管します。保管期間は1か月です。

### 5.2 ロッカー
希望者には、4Fに個人ロッカーを貸し出します。総務部に申請してください。退職・異動のときは鍵を返却してください。
