# 請求書・支払処理の手順（経理部内）

株式会社サンプル 経理部（ダミー資料。経理部内のみ公開）
2026年4月1日版

## 1. 請求書の受け取り

### 1.1 受け取りの経路
取引先からの請求書は、次の経路で受け取ります。
- 電子請求書：請求書受領システムに取引先が直接アップロードする
- メール：invoice@example.co.jp に届いたものを、経理部が請求書受領システムに登録する
- 郵送：総務部から経理部の郵便ボックスに届いたものを、スキャンして登録する

### 1.2 登録期限
請求書は、受け取ってから3営業日以内に請求書受領システムに登録してください。

## 2. 確認と承認

### 2.1 確認する項目
請求書を登録したら、次の項目を確認します。
- 取引先が取引先マスタに登録されているか
- 発注書・検収書と金額が一致しているか
- インボイスの登録番号が国税庁のサイトで有効か
- 支払期日が契約の条件と一致しているか

### 2.2 承認の流れ
請求書の承認は、金額に応じて次のとおり行います。
| 金額（税込） | 承認者 |
| --- | --- |
| 50万円未満 | 発注部署の課長 |
| 50万円以上300万円未満 | 発注部署の部長 |
| 300万円以上 | 管理本部長 |

## 3. 支払い

### 3.1 支払日
取引先への支払いは、毎月10日と25日の2回行います。支払日が休日の場合は、前の営業日に支払います。

### 3.2 支払データの作成
支払日の3営業日前に、承認済みの請求書から支払データを作成し、経理部長の承認を得てから、インターネットバンキングで送金予約をします。支払データの作成者と送金の承認者は、別の人にしてください。

### 3.3 振込手数料
振込手数料は、契約で取引先負担と定めた場合を除き、会社が負担します。

## 4. 取引先マスタ

### 4.1 新規取引先の登録
新しい取引先と取引を始める場合は、発注部署が「取引先登録申請」を提出し、経理部が反社会的勢力のチェックと振込口座の確認を行ってから登録します。

### 4.2 振込口座の変更
取引先から振込口座の変更の連絡があった場合は、必ず取引先の担当者に電話で確認してから変更してください。メールだけの依頼で変更してはいけません（なりすましによる詐欺を防ぐため）。

## 5. 月次決算

### 5.1 締めのスケジュール
| 日程 | 作業 |
| --- | --- |
| 翌月3営業日 | 経費精算・請求書の締め |
| 翌月5営業日 | 売上・仕入の計上 |
| 翌月7営業日 | 月次試算表の作成 |
| 翌月10営業日 | 経営会議への報告 |
