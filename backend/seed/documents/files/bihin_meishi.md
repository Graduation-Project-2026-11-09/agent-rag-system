# 備品・名刺の申請手順

株式会社サンプル 総務部（ダミー資料。実在の会社とは関係ありません）
2026年1月1日版

## 1. 事務用品

### 1.1 共用の事務用品
ボールペン、ノート、付箋、クリップなどの共用の事務用品は、各フロアの備品棚に置いてあります。自由に使ってかまいません。在庫が少なくなっていたら、総務部（内線3100）に連絡してください。

### 1.2 備品棚にない事務用品
備品棚にない事務用品が必要な場合は、社内ポータルの「備品購入申請」から申請します。1件あたり10,000円未満のものは所属長の承認だけで購入できます。10,000円以上のものは、総務部長の承認も必要です。

### 1.3 届くまでの日数
申請が承認されてから、通常3〜5営業日で届きます。急ぎの場合は、申請の「備考」に希望の納期を書いてください。

## 2. 家具・機器

### 2.1 机・椅子・モニター
机・椅子・モニターなどの家具・機器の追加や交換は、総務部に「什器変更申請」を提出します。体調の理由（腰痛など）で特別な椅子が必要な場合は、産業医の意見書を添えてください。

### 2.2 PC・スマートフォン
PC・スマートフォン・周辺機器（キーボード、マウスを除く）は、情報システム部が管理しています。「PC・アカウント利用ガイド」を参照してください。

## 3. 名刺

### 3.1 名刺の作成
名刺は、社内ポータルの「名刺作成申請」から申請します。氏名・部署・役職・電話番号・メールアドレスは人事システムの登録内容が自動で入ります。英語表記を裏面に入れる場合は、申請時に選択してください。

### 3.2 枚数と納期
名刺は1回の申請で100枚を作成します。申請から5営業日で、所属部署の郵便ボックスに届きます。

### 3.3 作り直しが必要なとき
次の場合は、名刺を作り直してください。費用は会社が負担します。
- 異動・昇格で部署や役職が変わったとき
- 氏名が変わったとき（旧姓使用を選んだ場合を除く）
- 電話番号やメールアドレスが変わったとき

### 3.4 名刺の廃棄
古い名刺は、シュレッダーにかけるか、各フロアの機密文書回収箱に入れてください。

## 4. 社員証

### 4.1 社員証の再発行
社員証を紛失・破損した場合は、すぐに総務部に連絡し、「社員証再発行申請」を提出してください。紛失の場合、再発行の費用として1,000円を給与から控除します。再発行までの間は、1F 受付で仮入館証を受け取ってください。

### 4.2 社員証の写真の変更
社員証の写真を変更したい場合は、総務部に申請してください。年に1回まで無料で変更できます。

## 5. 社用の印刷物

### 5.1 封筒・レターヘッド
会社のロゴ入り封筒やレターヘッドは、総務部の発送ボックスの横に置いてあります。大量に必要な場合（100枚以上）は、事前に総務部に連絡してください。

### 5.2 パンフレット・チラシ
会社案内のパンフレットやイベントのチラシの作成は、マーケティング部が担当しています。
